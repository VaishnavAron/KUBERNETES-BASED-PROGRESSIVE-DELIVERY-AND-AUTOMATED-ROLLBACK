Operational Demonstration Playbook
▶ Scenario A: Successful Canary Promotion

Deploys healthy version (yellow). Passes Prometheus analysis, advances traffic 20% → 40% → 60% → 80% → 100%.

# 1. Trigger healthy release
kubectl argo rollouts set image canary-demo canary-demo=argoproj/rollouts-demo:yellow

# 2. Watch canary steps & analysis
kubectl argo rollouts get rollout canary-demo --watch
▶ Scenario B: Faulty Release & Automated Rollback

Deploys failing version (bad-red). Prometheus detects errors, Analysis fails, Argo automatically aborts release.

# 1. Trigger failing release
kubectl argo rollouts set image canary-demo canary-demo=argoproj/rollouts-demo:bad-red

# 2. Confirm automated abort & zero downtime
kubectl argo rollouts get rollout canary-demo
